#Кибербезопасность #ЭтапыАтаки #CKCLM

Это общеизвестная модель, которая является первой универсальной моделью, описывающей атаку. В ней разделяют 7 этапов атаки

|         Название         |                          Описание                           |
| :----------------------: | :---------------------------------------------------------: |
|    [[Reconnaissance]]    |       Разведка для сбора информации об инфраструктуре       |
|  [[Weaponization]]<br>   |     Вооружение ПО и инструментами для совершения атаки      |
|       [[Delivery]]       |         Доставка ПО на устройства в инфраструктуре          |
|     [[Exploitation]]     |          Эксплуатация уязвимостей в инфраструктуре          |
|     [[Installation]]     |   Установка вредоносного ПО на устройства инфраструктуры    |
| [[Command and Control]]  | Командование скомпрометированным устройством и его контроль |
| [[Actions on objective]] |   Действия по достижению цели атаки (кража, шпионаж и тп)   |
