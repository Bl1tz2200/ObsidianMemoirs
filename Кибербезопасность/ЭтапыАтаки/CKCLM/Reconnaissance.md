#ATTNCK 

Reconnaissance (Разведка) -  это процесс сбора информации об инфраструктуре и уязвимостях компании, который выполняют, чтобы определить, какие действия могут быть выполнены для ее компрометации

# Инструменты
## Коллекция массивов для перебора
- [YAWR](https://github.com/empty-jack/YAWR/tree/master) - репозиторий с большим количеством списков для перебора паролей, доменов, файлов и тд
## Перебор доменных имен
- [DNSDumbster](https://dnsdumpster.com/) - сайт, позволяющий найти все поддомены
- [Subfinder](https://github.com/projectdiscovery/subfinder) - проект на GO для перебора поддоменов
## Сканеры сети
- [Nmap](https://nmap.org/) (И [zenmap](https://nmap.org/zenmap/) как GUI к нему в придачу) - стандартный сканер сети
- [Masscan](https://github.com/robertdavidgraham/masscan) - ускоренный сканер сети для массового сканирования
## Поиск разделов
- [ffuf](https://github.com/ffuf/ffuf) - утилита для поиска разделов веб-приложений, встроена в kali ([здесь](http://ffuf.me/) можно протестить)
